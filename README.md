# README #

This repo contains several ideas about automation, i.e. home automation, Arduino projects, ESP8266 projects, robots, etc.

For this to run we need a PC with the Arduino IDE installed plus some other libraries (described later), or a c++ compiler (usually the MS compiler). 
We need the hardware too, of course: Arduino, sensors, etc.
